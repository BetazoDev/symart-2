# Symart

Demo del rediseño de [symart.com.mx](https://symart.com.mx/) sobre el layout Home-3 de GearO, pasado a Next.js y Tailwind.

Incluye tienda con filtros y vistas, ficha de producto con miniaturas a la derecha, búsqueda, lista de deseos y carrito. Los precios son de referencia. El catálogo, las fotos y los textos salen del sitio y de Instagram de Symart.

```bash
npm install
npm run dev
```

Abre http://localhost:3000.

Las rutas `app/api/products` dejan el contrato listo para sustituir el catálogo local por un backend en Node.
